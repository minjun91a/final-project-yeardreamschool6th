## 프로젝트 소개

한의결은 한의사가 환자의 증상 표현으로 병증 후보를 찾고, 기업 원문과 연결 처방·약재 정보를 확인하며 상담과 처방 작성을 이어가는 웹서비스입니다. 안내데스크는 접수·대기 등록과 전달된 처방전의 조회·출력을, 한의사는 상담·근거 검토·처방 작성을, 원장은 직원 초대·승인·계정 관리를 담당합니다.

## 소스와 자료의 기준

소스 81개 파일은 GitHub가 제공한 고정 커밋 ZIP에서 추출하고, 각 파일의 Git blob 해시를 해당 커밋의 트리와 대조했습니다. 원본 코드를 수정하지 않았으며 제출용으로 추가한 파일은 `backend/.env.example`뿐입니다. 기존 통합 검증 기준은 `c9f3636`이고 제출 main `421c48b`는 그 직후 Python 3.10에서도 원본 파일 해시를 계산할 수 있도록 `backend/catalog.py`를 수정한 커밋입니다.

설계·관리 자료는 팀이 작성한 문서의 최종 보유본입니다. 요구사항정의서는 전달받은 2026-11-10 멘토링 보완본, UI설계서는 2026-11-10 보유본, API설계서는 v1.3, WBS는 팀의 요청에 따라 2026-11-24 최종 완료 기준으로 작업 상태 29개를 모두 완료로 정리한 Excel 파일입니다. 기존 시작일을 기준으로 O 표시를 작업일정에 분배하고, 최종 점검·오류 수정·시연 일정은 11월 24일까지 반영했습니다. 상태와 일정 구간은 초록색이며 비고의 11월 20일 기록은 과거 작업 이력으로 보존했습니다. VBA 모듈은 없습니다. API설계서는 실제 원본 형식인 Markdown입니다. 문서별 작성 시점과 제출 소스 커밋은 구분해 확인해 주세요.

기업 제공 원문·관계를 검색과 조회에 사용했습니다. 병증 44개와 연결 고유 처방 417개는 감기·두통·소화불량에서 선정한 초기 검색 범위입니다. 전체 기업 데이터의 규모나 검색 정확도를 뜻하지 않습니다. 영상은 가상 데이터 시연이며 개발 검증 결과와 구분합니다.

## 실행 환경을 구성할 때 필요한 항목

서비스 실행에는 별도의 PostgreSQL 스키마·데이터, 기업 원본과 검색용 자료, 모델·토크나이저와 실행 도구, 환경변수 설정이 필요합니다. 제출 ZIP에는 이러한 운영 자료와 비밀값을 넣지 않았습니다. 개발 DB 환경은 기존 전달 자료 기준 PostgreSQL 17.11, public 스키마, pgvector 0.8.7입니다.

설정 항목은 `01_소스코드/km-cdss-project/backend/.env.example`에서 확인할 수 있습니다. 실행 환경에서 해당 파일을 `backend/.env`로 복사하고 값을 채웁니다. `DATABASE_URL`은 DB 접속, `KM_CDSS_DATA_ROOT`는 검색 자료, `KM_CDSS_CATALOG_ROOT`와 `KM_CDSS_CATALOG_WORKBOOK`은 기업 조회 자료, 모델·서버 항목은 AI 실행 경로를 가리킵니다. 실제 SMTP와 API 키는 실행 환경에서 별도로 설정합니다.

환경 준비 후 프런트엔드는 `frontend/`에서 `npm ci`와 `npm run dev`, 백엔드는 필요한 Python 의존성 설치와 설정 후 `backend/`에서 `python -m uvicorn main:app --host 127.0.0.1 --port 8000`으로 실행하는 구성입니다. AI 실행 패키지 고정 목록은 `backend/requirements-local-model.txt`와 GPU 안내 문서를 참고합니다. 이 파일은 모델 실행 의존성 목록이며 백엔드 전체 의존성 잠금 목록은 아닙니다.

## 검증 결과를 읽는 기준

기존 2026-11-23 통합 검증에서는 백엔드 82개, 프런트엔드 5개 회귀 검사와 빌드가 통과했습니다. 이번 2026-11-25 제출 준비에서는 최신 main으로 백엔드 DB 비의존 검사 60개, 프런트엔드 5개, 빌드와 Python 소스 구문을 다시 확인했습니다. DB가 필요한 22개 검사는 이번에 생략했고 기존 통합 결과와 구분했습니다. 상세 조건과 해석 범위는 `04_검증결과/테스트결과_요약.pdf`에 있습니다.

## 포함하지 않은 항목

발표대본과 발표 운영표는 포함하지 않았고, 제출용 PPT와 UI설계서의 발표 노트도 제거했습니다. 슬라이드와 시연 영상은 보존했습니다. 실제 `.env`, DB 백업·DB 파일, 계정·초대 토큰·개인키, 기업 원본 대량 자료, 임베딩 벡터 파일, 모델 가중치·캐시·실행 바이너리, `.git`, `node_modules`, 가상환경, 빌드 결과·임시 로그를 제외했습니다. 단위 검사 코드의 `example.test` 등 가상 주소와 고정 테스트 입력은 원본 소스의 일부로 유지했습니다.
