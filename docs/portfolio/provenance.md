원본에 별도 라이선스가 없는 상태에서 팀 공동 코드와 기업 자료에 새 오픈소스 라이선스를 일괄 적용하지 않았습니다. 원본 저작과 이용 조건은 유지됩니다.

## 화면·영상

`assets/evidence.png`, `assets/prescription.png`, `assets/history.png`는 팀원이 전달한 최종 시연영상의 프레임입니다. 원본 프레임을 보존했으며 기능이 구현된 것처럼 화면 내용을 새로 만들지 않았습니다.

시연의 환자·병증·처방·약재는 가상 데이터입니다. 검색·생성 품질의 실제 평가 자료나 실제 환자 기록이 아닙니다.

## 데이터와 기록

기업의 원문·관계를 사용한 프로젝트이며, 포트폴리오에 기업 원본 파일·원문 스냅샷·임베딩 행렬·DB 백업을 새로 공개하지 않습니다. 초기 검색 범위와 전체 카탈로그를 구분하고, 고유 처방 수와 연결 관계 행 수도 서로 다른 단위로 설명합니다.

`docs/제출자료/`는 팀 제출용 산출물의 보관본입니다. 그 안의 소스는 고정 커밋 스냅샷이고 실제 개발 소스는 저장소 루트에 있습니다. WBS는 팀 요청으로 11월 24일 완료 기준으로 정리한 관리 자료이며 독립적인 품질 평가나 임상 검증의 증빙은 아닙니다.

## 공개에서 제외한 항목

실제 `.env`, 인증키·개인키·초대 토큰, DB 파일·백업, 모델 가중치·토크나이저 캐시, 기업 원본·벡터 파일, 설치 의존성·가상환경, 개인 연락 내용과 원시 로그, 발표대본·PPT 발표자 노트는 새 공개 자료에 포함하지 않았습니다. 코드의 고정 테스트 입력과 예시 주소는 실사용 계정 정보와 구분합니다.
